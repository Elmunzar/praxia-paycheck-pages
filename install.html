Install Praxia PayCheck

Private

You’ve been invited to try Praxia PayCheck — a private, offline estimator for UK NHS pay, tax, pension and take-home. It’s a private (unlisted) App Store app: you get it from a link, and it unlocks with an access code.

Install on your iPhone or iPad

  1. Tap the link you were sent — it opens Praxia PayCheck on the App Store.
  2. Tap Get (or the cloud icon) to install it, just like any App Store app.
  3. Open the app and enter your access code — the code you were given, which looks like 30D-XXXXXX-XXXXXX. That unlocks it.

No account, no sign-up, no password. Everything you enter stays on your device and is never sent anywhere.

Good to know

  • Praxia PayCheck is a private app — it isn’t searchable on the App Store, so it can only be installed from the link you were sent.
  • A 30-day code unlocks it for 30 days from the moment you first enter it; a lifetime code never expires.
  • Lost your code, or it won’t unlock? Ask whoever shared the app with you, or email support@bagouri.uk.
